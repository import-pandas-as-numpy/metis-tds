# Code of conduct

## Our standards

We want participation in this project to be safe, constructive, and professional. Be respectful, assume good faith, accept technical criticism gracefully, and focus discussion on evidence and the work.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, deliberate intimidation, publishing another person's private information, or disrupting project spaces in bad faith.

Security research does not excuse targeting contributors, unrelated systems, or infrastructure without authorization. Do not publish captured credentials, personal data, or identifying telemetry in project discussions.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates these standards. Decisions should consider context, impact, recurrence, and the safety of affected people.

Use GitHub's private reporting or abuse-reporting features for sensitive conduct concerns. If a private project channel is not available, ask the repository owner for one without placing sensitive details in a public issue. Reports will be handled as privately as practical, and retaliation against a good-faith reporter is prohibited.

This code applies in repository spaces and when someone is publicly representing the project.

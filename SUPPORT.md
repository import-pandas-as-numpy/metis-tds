# Support

Metis is an early-stage security research project maintained on a best-effort basis.

- Use a bug report for reproducible defects.
- Use a feature request for proposed protocol or deception behavior.
- Use [GitHub private vulnerability reporting](SECURITY.md) for security issues.
- Consult [the deployment guide](docs/deployment.md) before exposing an instance to the Internet.

Do not post live credentials, raw attacker payloads, private keys, access tokens, or identifying honeypot telemetry in public discussions.
